# Origin and checks of the tutorial example

The fixed synthetic dataset is `D0_screen_28062027` (seed 28062027; 1,200 observations). Personal resources and acute stress were generated independently from truncated normal distributions. The generating controls were alpha = 0 + 0.8 × resources and beta = 0.25 + 1 × stress. The canonical state was drawn with `cusp::rcusp()`; the supplied analysis variables are standardized.

The example was selected for stable numerical output from a fixed list of three previously generated candidates, in the order 28062027, 28062028, 28062029. Selection used convergence, agreement between fits, curvature checks, and agreement with a more precise diagnostic reference. It did not use coefficient significance or model-comparison results. The additional selection protocol was an internal amendment, not a preregistration. These checks concern this fixed teaching example; they do not establish general performance of the generator or package, or coverage of confidence intervals.

`native_reader_reproduction_20260924.zip` preserves the first author's native-R reader run using unmodified cusp 2.3.8. It contains the original console output, fitted object, tables, graphics, warnings/errors, and session information. Opening the archive runs no analysis. Historical generation scripts, protocols, and detailed selection records are retained separately by the first author and are not included in the public reader release. The fixed data, scripts, recorded outputs, and this native reader archive are published on Zenodo: https://doi.org/10.5281/zenodo.23079540.
