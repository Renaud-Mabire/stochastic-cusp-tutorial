# Provenance of the fixed teaching example

These files are unchanged copies from the full v1.7.0 companion package. They document the fixed candidate, candidate-check outcomes, the internal protocol amendment, and the native reader run of September 24, 2026. The ZIP contains the original recorded output, including session information and graphics. Opening it does not run an analysis.

The candidate was selected after numerical screening. The protocol amendment was internal, not preregistered. These files concern this teaching example and do not constitute general validation of cusp or of its data-generating configuration.

This folder is a selected record, not the complete historical validation archive. The full package retains the frozen final-check project, native final-check results, historical scripts, and intermediate outputs. Those archives should be retained in the archival companion deposit when it is finalized. Paths in the original provenance records refer to that original project layout; they are historical records, not repository execution instructions.
